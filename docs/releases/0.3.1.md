# Python 0.3.1

Tracking: [Python #50](https://github.com/teaql/teaql-python/issues/50) and
[conformance #109](https://github.com/teaql/teaql-conformance/issues/109).

The optional `teaql[telemetry]` extra supplies the standard SDK module. Context
startup reports support and the three activation variables; enabling them records
full safe traces, metrics and logs. Disabled startup does not load SDK resources.

Expanded masked SQL carries the original physical identity. Owned pipelines keep
customer globals unchanged and bound admission, flush and shutdown. Export failure
does not change business outcomes or independent audit. Scalar stream diagnostics
count delivered entities, not merely prefetched rows.

Regenerate libraries for current request-tree/search metadata and ordinary list
pagination. Source/internal evidence is retained in the conformance
`2026-10-13-standard-telemetry-onboarding` report; final internal/public package and
signed-tag verification remain separate gates.
